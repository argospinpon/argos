# ARGOS Pong

Ping pong en el navegador en el que la pelota es la cara de ARGOS, el robot guía hospitalario del Grupo 2 de IngenIA Robótica (UPM).

**Jugar:** abre el enlace de GitHub Pages del repositorio, o descarga `index.html` y ábrelo con doble clic.

## Modos
- **1 jugador:** contra la máquina, con tres niveles (Fácil, Normal y Difícil).
- **2 jugadores:** en el mismo ordenador.

## Controles
| Acción | 1 jugador | 2 jugadores |
| --- | --- | --- |
| Mover la pala | Ratón, dedo, W/S o ↑/↓ | Amarilla: W/S · Naranja: ↑/↓ (en móvil, cada uno toca su mitad) |
| Empezar / revancha | Espacio, clic o toque | Espacio, clic o toque |
| Pausa | P o Esc | P o Esc |

Gana quien llegue antes a 7 puntos.
